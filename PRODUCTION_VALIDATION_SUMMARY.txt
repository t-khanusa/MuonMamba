IMPLEMENTATION DETAILS
======================
Both CUDA and PyTorch implementations follow identical logic:

1. Compute b_t = alpha * delta * B * u element-wise
   - u: [B, D, L] input
   - delta: [B, D, L] delta
   - B: [D, N] matrix parameter
   - b_t: [D, N] result for each (batch, timestep)

2. Convert to BF16 BEFORE normalization
   - Matches production kernel exactly
   - Critical for numerical stability

3. Compute norm from BF16 values
   - norm = sqrt(sum(bf16_val^2) + 1e-8)

4. Normalize in BF16
   - X = (b_t / norm).bfloat16()

5. Apply transpose for tall matrices
   - If D > N: transpose to [N, D] for Newton-Schulz iterations

6. Newton-Schulz 5 iterations
   - Coefficients: a=3.4445, b=-4.7750, c=2.0315
   - Gram matrix A = X @ X.T (FP32 accumulation, BF16 output)
   - Polynomial B = b*A + c*A² (BF16 arithmetic)
   - Update X = a*X + B@X (BF16 arithmetic)

7. Transpose back if needed
